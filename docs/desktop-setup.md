# 电脑回顾页

运行 `scripts/start-desktop.ps1`，程序只绑定 127.0.0.1，自动打开带一次性启动凭据的本机页面。不要分享该启动链接。端口被占用时会选择其他空闲端口。

在设置里填写私人服务器 HTTPS 根地址和账号密码；密码不持久保存，登录令牌与模型密钥使用当前 Windows 用户 DPAPI 加密。更换 Windows 用户或重装系统后需要重新登录。不要将本机数据目录上传公开仓库。

回顾区以用户输入为主；文本自动保存到本机，再进入同步队列。断网时可以继续编辑；冲突不会静默覆盖，需选择保留或放弃本机版本。AI 回答单独显示，只有点击加入才进入正文；不发送图片、笔记库文件。模型未配置时不伪造回答。

归档先选库，再选文件夹，默认新建；追加需明确选择已有 Markdown。预览后确认写入，图片在笔记旁 `_attachments`，不依赖云端链接。若目标发生外部修改或图片尚未下载完整，归档会停止，保留草稿。

每天上海时间19:00检查待回顾数量，晚启动则补提醒，同一天只认领一次。程序不运行、电脑关机或通知被 Windows 禁用时不会出现系统通知，页面的待回顾列表仍可使用。开启自启动必须由你主动执行：

```powershell
./scripts/configure-startup.ps1
# 撤销
./scripts/configure-startup.ps1 -Disable
```

安装和测试不会自动修改你的登录自启动。当前没有托盘图标；从终端启动时需保持进程运行。
