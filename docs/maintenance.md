# 日常维护

2026-10-25 产品范围已精简：仅保留记录、同步、手动回顾和 Obsidian 归档，不再配置模型服务、密钥或内置 AI 对话。旧版本已有的配置与对话数据兼容保留，本次不清库；界面不再显示相关入口，也不提供历史对话或模型调用接口。

每周检查磁盘空间、容器健康、备份时间、一次异地副本和同步失败数量。单图上限20MiB，单条20张/合计200MiB；这不是整个账号的总容量配额。服务器磁盘应设置告警，空间不足时不要清空手机数据。

升级前做并校验备份，保留上一份源码与镜像。当前数据库版本1，尚无跨版本迁移。未来必须增加迁移测试，不可使用删除数据库作为升级方法。Android升级必须保持包名与签名密钥。

手机系统可能限制 WorkManager 后台联网；首版有网络约束任务、15分钟周期兜底、前台重试和手动重试，但不保证一联网立即上传。请观察同步状态。需要时由你在华为应用启动管理中允许后台活动；不要为了测试关闭全局安全设置。锁屏长时间后台、重启和电池管理仍须专项验收。

2026-10-24 P40 验收发现已开启流量节省，验收任务因此等待后台 CONNECTIVITY 条件。按需只允许“点子回声”的后台计量数据，保持全局流量节省。具体实测与配置变更见 [P40 后台验收](p40-verification.md)；该设置不解决未备案的公网拦截。

云端登录令牌过期后重新登录；本机数据保留。不要因为上传失败而卸载手机 App。设置中的导出可保留未同步记录和图片；含私人内容，妥善存放。

默认不记录原文/密码/令牌的请求日志。排错时只共享错误类别、版本和时间，不直接发送数据库或完整日志。应用版本更新后复跑验收清单。

## 当前 Windows 提醒与自启动

2026-10-24 已启用当前用户登录后后台启动。使用项目内 `pythonw.exe`，无终端窗口、不在每次登录时自动弹出浏览器。请勿移动或删除整个项目目录，否则需要重新运行 `scripts/configure-startup.ps1` 设置路径。

北京时间 19:00 后，有本机已知的待回顾点子时每天提醒一次；当天晚些时候开机/登录可补提醒，没有待回顾内容则不提醒。电脑关机时不能弹出通知；云端无法连接时也不能知道尚未同步到电脑的新点子。用户已确认测试通知及点击打开回顾页正常，实际下次登录和 19:00 触发仍需观察。

关闭自启动（不删除记录）：在项目目录运行 `./scripts/configure-startup.ps1 -Disable`。关闭自启动不会终止已经运行的回顾服务。

Ubuntu 原生版自动备份使用独立的维护包，详见 [备份维护说明](../deploy/native/BACKUP-README.md)。本地包已准备不等于服务器已启用；以服务器日志中的 `restore_checked: true` 和定时器 active 为验收依据。
