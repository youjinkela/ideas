# 回顾页无价值删除 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 红色回顾按钮和黑色“无价值”按钮；按用户后续明确要求，确认后删除电脑、云端和手机上的源点子与图片，离线端下次同步生效。

**Architecture:** 账号缓存保存仅含点子ID的本地删除标记并持久排队，云端删除原文/回顾/状态/历史事件与无其他引用的图片，保留仅含UUID的删除事件阻止旧副本复活。手机先拉取删除事件再上传，处理410竞态，游标按服务器/账号隔离。图片清理持久重试。已导出的 Obsidian 文档与历史备份不改写。

**Tech Stack:** Existing FastAPI / SQLite / JavaScript / Playwright.

**Spec:** User request in this conversation; final deletion-scope reply: 都不保留 (supersedes initial local-only assumption).

## Constraints

- 红色只改变下方“留待下次”“已回顾”按钮；左侧已回顾标签仍为黄色。
- 删除前确认，取消保留编辑；当前发散先保存，删除失败保留页面。
- 本地接口沿用会话/Origin/CSRF保护，删除限制在当前账号缓存。
- 删除服务器和手机上的源点子/图片；保护其他点子/账号/草稿共用附件，不删除 Obsidian 文档；不在真数据上执行删除验收。
- 历史备份不自动改写；离线设备及未更新的部署不宣称已经完成全端删除。
- 删除执行期间阻止新编辑；远端删除遇到旧编辑稿时允许先复制，再切换，不让无效草稿卡死所有操作。
